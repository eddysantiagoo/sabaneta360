# Sabaneta 360

El patrimonio de Sabaneta en tu teléfono: fichas, rutas y el mapa del inventario municipal.

Este repositorio solo publica las versiones de la app para Android. Descárgala desde
[Releases](https://github.com/eddysantiagoo/sabaneta360/releases/latest) o desde
[eddys.dev/sabaneta360](https://eddys.dev/sabaneta360).

Requiere Android 7.0 o superior.
